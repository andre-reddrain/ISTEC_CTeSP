# Design para a Web

**Princípios Fundamentais**:
1. As páginas estão interligadas
2. Utilizadores controlam a navegação
3. Diversidade de dispositivos e contextos

**Layout**:
1. Desenho estético e minimalista - Mais controlo em dispositivos diferentes
2. Coerência
3. Sinal vs Ruído
4. Elementos destacados
5. Hierarquias Visuais claras (Grau / proximidade / enquadramento)
6. Acima da Dobra
7. Layouts dinâmicos

**Conteúdo**:
1. Pirâmide Invertida (Jornalismo)
2. Texto Sucinto
3. Links reconhecíveis / interpáginas

**Navegação**:
1. Estrutura, normalmente hierárquica
2. Elementos de navegação
  1. Menus
  2. Separadores
  3. Botões
3. Localização
4. Regresso a casa
