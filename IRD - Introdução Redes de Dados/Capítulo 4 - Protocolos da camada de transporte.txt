Capítulo 4 - Protocolos da camada de transporte (C4 OSI)
    - TCP -> Transmission Control Protocol
        - Orientado á ligação extremo-a-extremo. Terminais antes de iniciarem a comunicação de dados trocam 3 mensagens de controlo => Aceitarem e sincronizar a ligação.
        - Garante fiabilidade da ligação
            - Mensagens recebidas no terminal destino apenas entregues à aplicação sem erros e por ordem cronológica
        - Faz controlo de fluxo
            - Recetor informa emissor do volume máximo de dados
                - Usa mecanismo da janela deslizante (Campo Win) - Também faz controlo de erros (campos nºsequencia nºconfirmação = ACK)
        - 1 único controlo de fluxo e erros que pode conter dados de várias aplicações
            - Ex: Mensagem TCP -> Como tem 1 controlo de fluxo / erros, se uma parte da mensagem tiver erros, o TCP vai retransmitir TODA a mensagem.
            - Ex: Aplicação TCP -> Aplicações de dados c/ requisitos de transporte fiavel, ex: HTTP
    - UDP -> User Datagram Protocol
        - Não é orientado á ligação extremo-a-extremo
        - Não garante fiabilidade da ligação
        - Não faz controlo de fluxo e erros
            - Ex: Aplicação UDP -> Aplicações em que a rapidez/simplicidade seja mais importante do que a fiabilidade. Ex: Voz

- Protocolos que complementam os tradicionais: TCP ou UDP
    - RTP - Real Time Protocol => Complementa UDP
        - Objetivo: Recuperar sincronismo de pacotes no destino => Cabeçalho de pacotes RTP contém informação temporal (timestamp) do instante da transmissão do pacote de origem
    - SCTP (Stream Control Transmission Protocol)
        - Objetivo: Introduzir 3 melhorias relativas a TCP:
            1 - Controlo Multi-stream
                - Controlo de fluxo e erros individual para cada stream/aplicação
                - Se detetado erro numa stream apenas retransmite dados da mesma
            2 - Maior segurança contra ataques DOS (TCP Syn Flood)
                - Cliente tem que enviar 2ª mensagem a confirmar o seu pedido de estabelecimento de ligação para o servidor poder alocar recursos para a mesma
            3 - Multi-morning
                - 2 Terminais SCTP poderem ser endereçados por 2 endereços IP diferentes
