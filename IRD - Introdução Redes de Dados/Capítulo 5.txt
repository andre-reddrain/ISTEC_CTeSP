Capítulo 5 - Protocolo IP

- Principais características do IP
    - Funções correspondentes à camada de rede (C3 OSI)
    - Encaminhamento de mensagens entre redes diferentes // Base em endereços públicos, univocos e de significado universal
    - Comutação de pacotes
    - Sem conexão ou não orientada à ligação
    - Não efetua controlo de erros
    - Não garante QoS <=> Best effort

- Endereços IP V4
    32 bits = 4 octetos
        Rede | Terminal

        Rede - Routing feito com base prefixo de rede do endereço
        Terminal - Só tem significado no interior da sub rede

    Classe          Nº Máximo terminais
        A   1 + 3 = 16,7M
        B   2 + 2 = 64k
        C   3 + 1 = 254
    
    Vantagens de conceito de classes:
        - Valor do 1º octeto permite identificar a classe do endereço
        - Escolher classe de endereço em função do tamanho da rede = nº terminais
    Desvantagens das classes
        - Não optimiza uso de endereços IPv4
            - Potencia desperdício

Routers usam mascaras de rede para identificar prefixo de rede dos endereços IP destino processados
    Mascara de rede = Prefixo de rede '1's
                      Sufixo de terminal '0's
    Aplicação da máscara: Endereço IP destino AND
                          Mascara da rede =
                          Prefixo de rede de IP Destino
                          Termianl de rede de IP destino = 0

- Problemas IPv4
    - Crescimento de redes e terminais => Esgotamento de endereços disponíveis
    - Crescimento das tabelas dos routers para acompanhar crescimento das redes
    - Utilização de classes não optimiza uso de endereços IPv4
    - Necessidade de implementar medidas temporárias, antes da medida efetiva: Uso de IPv6
        - Routing sem classes
            - Não tem subnets
            - Supernets
        - Endereços
