Strings
- Genericamente, uma string é um conjunto de caracteres

Array de caracteres
- Precisa de um terminador que é o '\0'
- Como é um array, a dimensão é fixa
- O espaço ocupado em memória é só a dimensão do array

Objeto String
- Não tem terminador
- Não tem dimensão fixa
- Pode-se usar da mesma forma que se usa os outros tipos (atribuições, comparações)

// Array
#include <cstring>
int main() {
    char nome[20], apelidos[20], nomeCompleto[40];
    cout << "Nome = ";
    cin.getline(nome, 20);
    cout << "O seu nome é " << nome << endl;
    cout << "Apelidos = ";
    cin.getline(apelidos, 20);
    strcpy(nomeCompleto, nome);
    strcat(nomeCompleto, " ");
    strcat(nomeCompleto, apelidos);
    cout << "Nome completo: " << nomeCompleto << endl;
    cout << "O seu nome tem " << strlen(nomeCompleto) << " caracteres";

    return 0;
}
