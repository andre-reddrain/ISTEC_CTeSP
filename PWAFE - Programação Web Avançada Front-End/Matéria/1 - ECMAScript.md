# ECMAScript

## O que é ECMAScript?
ECMAScript é um padrão de linguagem de script.
Base para linguagens como **JavaScript, JScript, ActionScript**.
Desenvolvido pela ECMA International, em 1997.

## Versões principais
- **ES3 (1999)** - Popularização do JavaScript
- **ES5 (2009)** - Introdução de JSON, strict mode, métodos de arrays.
- **ES6/ES2015 (2015)** - Mudanças significativas - classes, let/const, arrow functions.

### Funcionalidades ECMAScript 6
- **Arrow Functions** - Sintaxe simplificada para funções.
- **let e const** - Variáveis com âmbito de bloco.
- **Classes** - Introdução de sintaxe orientada a objetos.
- **Template Strings** - Manipulação de strings usando crases (`)

# Diferenças entre JavaScript e ECMAScript

## ECMAScript
- **Definição** - ECMAScript é a especificação padronizada que define a linguagem de script.
- **Objetivo** - Serve como base para a criação e a compatibilidade de diferentes implementações da linguagem de script.

## JavaScript
- **Definição** - JavaScript é uma implementação da especificação ECMAScript.
- **Objetivo** - Fornecer uma linguagem de programação para desenvolvimento web e outros tipos de desenvolvimento.

### Principais Diferenças
- **Alcance** - ECMAScript é a especificação, enquanto JavaScript é uma implementação da especificação.
- **Funcionalidades Adicionais** - JavaScript inclui APIs e funcionalidades específicas do navegador.
- **Compatibilidade** - JavaScript pode ter diferenças de implementação entre navegadores e ambientes.
