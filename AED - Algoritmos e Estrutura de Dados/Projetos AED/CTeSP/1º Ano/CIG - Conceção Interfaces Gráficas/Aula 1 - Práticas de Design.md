# Práticas de Design

## Modelo de Card
- P0 - Reconhecer é melhor que lembrar
- P1 - Estímulos têm de ser óbvios
- P2 - Memória de longa duração define as pistas
- P3 - Muitas opções é pior que poucas (Lei de Hick)
- P4 - Demasiada informação exige mais.
- P5 - Alvos perto e maiores (Lei de Fitts)
- P6 - Qualquer interface torna-se compreensível
- P7 - Evitar incerteza na interface
- P8 - Interface deve suportar ações racionais
- P9 - A atividade na interface deve ser descrita racionalmente

## Modelo de Norman:
- P1 - Formar o objetivo
- P2 - Formar a intenção
- P3 - Especificar a ação
- P4 - Executar a ação
- P5 - Percecionar o estado do mundo
- P6 - Interpretar o estado do mundo
- P7 - Avaliar o resultado

# Estilos de Interação

## Menus
- Vantagens:
    - Autoexplicativos
    - Requerem pouca memória
    - Bom para principiantes
    - Fácil gestão de erros
- Desvantagens:
    - Ineficientes para muitas opções
    - Obrigam a uma sequência de passos
    - Gastam espaço no ecrã

## Comandos
- Vantagens:
    - Comandos simples equivalem a muitos menus
    - Bons para tarefas repetitivas (scripts)
    - Não ocupam espaço no ecrã
- Desvantagens:
    - Dificuldade de aprendizagem
    - É necessário ter uma memória treinada

## Formulários
- Vantagens:
    - Requerem pouca memória
    - Melhores que menus na ocupação de espaço
- Desvantagens:
    - Propício a erros, devido ao uso do teclado
    - Necessário conhecimento sobre o tipo de dados
    - Inflexíveis

## Língua natural
- Vantagens:
    - Interface natural para o utilizador
    - Fáceis de usar e aprender
    - Extremamente flexível
    - Pouco uso de ecrã
- Desvantagens:
    - Vaga e ambígua
    - Assume-se conhecimento do domínio
    - Necessário confirmação
    - Funciona mal com ruído ambiente

## Manipulação direta
- Vantagens:
    - Forte sensação de controlo de interface
    - Fácil de aprender e recordar
    - Fazer em vez de comandar
- Desvantagens:
    - Ineficiente para peritos
    - Não são autoexplicativas
    - Usa espaço no ecrã
    - Não suporta ações repetidas
    - Mais desafiante para os designers

### Resumo
- **Boas práticas de design de interfaces são importantes**
- A perceção humana é limitada
- **Execução e avaliação são as fases de interação**
- **Interação envolve dispositivos de entrada e saída**
- **Cada dispositivo tem vantagens e desvantagens**
